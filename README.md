# AUTOPEEK

MVP לחיפוש מידע ציבורי על רכב בישראל לפי מספר רישוי. נבנה ב־Next.js App Router ומבצע שאילתות ל־CKAN Datastore API של data.gov.il בצד השרת.

כתובת האתר המיועדת: [autopeek.co.il](https://autopeek.co.il). חיבור הדומיין דורש פריסה והגדרות DNS נפרדות.

## הפעלה

```bash
pnpm install
pnpm dev
```

פתחו http://localhost:3000. אין צורך במפתח API.

## מקורות ומגבלות

- פרטי רכב, צמיגים, דלק, טסט ותוקף רישוי: מאגר מספרי רישוי של כלי רכב פרטיים ומסחריים.
- נסועה: נתון הטסט האחרון בלבד, לא היסטוריה רציפה או טיפולים.
- בעלויות: תאריך וסוג בעלות בלבד, ללא זהות בעלים.
- קובצי ההיסטוריה אינם מכסים כל מספר רישוי. כאשר חסרה בהם רשומה, האתר מציג רק את מועד הטסט וסוג הבעלות הנוכחית אם הם קיימים במאגר הרכב; אין להסיק מהיעדר הרשומה שלא היו בעלים קודמים או שלא בוצע טסט.
- ריקולים: מאגר רכבים שלא ביצעו קריאת שירות. היעדר רשומה אינו אישור שאין ריקול.
- ביטול סופי: חיפוש בשלושה קובצי תקופות. היעדר רשומה אינו אישור סטטוס רשמי.
- WLTP ומחיר יבואן: התאמה לפי קודי יצרן ודגם ושנת ייצור. אלו נתוני דגם, ולא בהכרח נתוני רמת הגימור הספציפית. מחיר יבואן אינו שווי רכב משומש.
- הודעות יצרנים כלליות על ריקולים אינן מקושרות באופן אמין למספר רישוי במאגר; מוצג קישור למקור בלבד.

נתוני המאגר עלולים להשתנות או להיות חסרים. האתר אינו תחליף לבדיקה מקצועית או לאימות רשמי.

## דוח PDF והגנה על מקורות הנתונים

לאחר חיפוש רכב שנמצא, ניתן להוריד דוח PDF בעברית. הדוח נוצר בשרת מתוך אותם מאגרים ומשקף את הנתונים בזמן ההפקה. גופן Noto Sans Hebrew כלול תחת רישיון OFL שב־`assets/fonts/OFL.txt`.

מספר רישוי נבדק בשרת לפני כל פנייה למאגר. תגובות מוצלחות של data.gov.il נשמרות במטמון לשעה; בקשות למאגר מוגבלות בזמן. ב־Netlify קיימות מגבלות קצב לפי IP גם לחיפוש (`6` בדקה) וגם לדוחות (`2` בדקה), לפני הפעלת הקוד בשרת. יש לוודא ב־Deploy log של Netlify שהכללים נטענו; Netlify מציינת שאכיפה עשויה להתעכב עד כ־10 שניות. הגבלות לפי IP אינן מונעות הצפה מבוזרת, ולכן בהיקף תעבורה גדול יש להוסיף הגנת WAF וניטור תעבורה.

## מידע למשתמשים

האתר מציג הפניה מרוכזת למאגרי משרד התחבורה בתחתית העמוד. עמודי `/terms`, `/privacy` ו־`/accessibility` מסבירים את מגבלות המידע, אופן עיבוד הבקשות ודרך הפנייה. דוח ה־PDF כולל אף הוא הבהרת מקור ואי־שיוך לשירות ממשלתי. לפני השקה מסחרית או שינוי בשימוש בנתונים יש לבדוק מחדש את תנאי הרישיון, הפרטיות והנגישות עם בעל מקצוע מתאים.
